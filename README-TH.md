# แม่แบบ Auto Update — สวนเที่ยงคืน

ไฟล์นี้เป็นแม่แบบที่ปรับจาก `package.json` และ `main.js` ที่ให้มา โดยคง App ID, ชื่อเกม, ไฟล์ HTML, vendor, NSIS และการตั้งค่าความปลอดภัยเดิมไว้

## ก่อนใช้

1. สำรองโฟลเดอร์เกมเดิม
2. คัดลอก `main.js` และผสาน/แทนที่ไฟล์เดิมหลังตรวจสอบแล้ว
3. ผสาน `package.json` นี้เข้ากับของเดิม อย่าเขียนทับโดยไม่ตรวจสอบไฟล์ที่โปรเจกต์จริงมีเพิ่ม
4. ใส่ GitHub repository จริงใน `build.publish`:
   - `YOUR_GITHUB_USERNAME`
   - `YOUR_GITHUB_REPOSITORY`
5. ต้องมีไฟล์ `สวนเที่ยงคืน.html` และโฟลเดอร์ `vendor` ตามโปรเจกต์เดิมในโฟลเดอร์เดียวกัน

## ติดตั้ง dependencies

เปิด Terminal ในโฟลเดอร์โปรเจกต์จริง แล้วรัน:

```bash
npm install
npm start
```

`npm start` ใช้ทดสอบเกมในโหมดพัฒนา โดยโค้ดจะไม่ตรวจอัปเดตในโหมดนี้

## เผยแพร่เวอร์ชันแรกที่มี Auto Update

เวอร์ชันเดิมที่ติดตั้งอยู่ไม่มีตัวตรวจอัปเดต ดังนั้นต้องแจก Setup เวอร์ชันเปลี่ยนผ่านให้ผู้เล่นติดตั้งด้วยตนเองหนึ่งครั้ง

1. กำหนด `version` ให้เป็นเวอร์ชันใหม่กว่าเวอร์ชันที่แจกไปแล้ว
2. สร้าง GitHub Release และตั้งค่า token สำหรับการเผยแพร่ใน environment ของเครื่องผู้พัฒนาหรือ CI เท่านั้น
3. สั่ง Build Setup สำหรับเวอร์ชันเปลี่ยนผ่าน:

```bash
npm run build
```

4. ทดสอบ Setup บนเครื่อง Windows แยกต่างหากก่อนแจก

## เผยแพร่อัปเดตครั้งถัดไป

1. แก้ `สวนเที่ยงคืน.html` และทรัพยากรที่จำเป็น
2. เพิ่มเลข `version` ใน `package.json` ทุกครั้ง เช่น `1.0.1` -> `1.0.2`
3. เผยแพร่ด้วย:

```bash
npm run publish
```

4. ตรวจสอบว่า GitHub Release มีไฟล์ Setup, ไฟล์ `.blockmap` (ถ้ามี) และ `latest.yml`
5. เปิดเกมเวอร์ชันที่มี Auto Update และทดสอบดาวน์โหลด/ติดตั้งจริง

## ข้อควรระวัง

- อย่าเปลี่ยน `appId` (`th.suantiamkhuen.game`) หรือชื่อผลิตภัณฑ์เดิมโดยไม่วางแผนย้ายแอป
- ห้ามฝัง GitHub token ใน `main.js`, HTML, `package.json` หรือไฟล์ที่แจกให้ผู้เล่น
- GitHub repository/release ต้องเข้าถึงได้จากตัวเกมที่ติดตั้ง หากใช้ private repository ต้องวางแผนการยืนยันตัวตนให้เหมาะสม
- ทดสอบการอัปเดตจาก Setup รุ่นเก่าบนเครื่องทดสอบก่อนเสมอ
- โค้ดนี้ไม่ได้เปลี่ยนวิธีเก็บเซฟใน HTML เดิม หากเกมเก็บเซฟใน `localStorage` อย่าล้างข้อมูลแอป และทดสอบว่าเซฟยังอยู่หลังอัปเดต
- ไฟล์นี้เป็นแม่แบบ ไม่ใช่ Setup.exe ที่ Build แล้ว และยังต้องใส่ชื่อ GitHub repository จริงก่อนเผยแพร่อัปเดต
